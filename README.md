# Codixel — пиксельные анимации

Ветка для пиксельных анимаций, которые делаются через скилл **codixel**.

Подход: не рисовать из головы, а идти от референса:

1. Референс-картинка от пользователя.
2. Пикселизация.
3. Риг (разбивка на части).
4. Анимация.
5. Проверка каждого шага с пользователем.

Каждая работа — отдельная папка в корне.
